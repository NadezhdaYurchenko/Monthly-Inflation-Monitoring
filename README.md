# Monthly-Inflation-Monitoring

Ежемесячная аналитика по инфляции: скрипт читает Excel с данными, считает показатели
и сохраняет Excel-отчет, где на каждом листе — таблица (за весь период, с 2002 г.)
и рядом редактируемые графики (с 2024 г.).

## Файлы

| Файл | Что это |
|---|---|
| `inflation_report.py` | весь код; **все настройки — в начале файла, блок «НАСТРОЙКИ»** |
| `inflation_report_run.ipynb` | ноутбук для запуска |
| `requirements.txt` | зависимости |

## Запуск

1. Положить `Месячная инфляция_Данные.xlsx` в папку с кодом.
2. В Jupyter выполнить ячейки ноутбука: `%pip install -r requirements.txt` (достаточно
   один раз), затем `%run inflation_report.py`.
3. Рядом появится `Месячная инфляция_Отчет.xlsx` (и PDF, если `EXPORT_PDF = True`).
   Результаты расчетов остаются в переменной `report`.

## Листы отчета

1. **Хедлайн и базовая** — (1) м./м.: SA-хедлайн, бледный nSA-хедлайн и закрашенный диапазон
   четырех мер базовой инфляции (от минимальной до максимальной); (2) г./г.: хедлайн линией,
   диапазон базовой, SAAR хедлайна и каждой меры базовой — точками разной формы.
2. **Вклады** — вклады в SA-хедлайн м./м.; набор компонентов задается в `CONTRIBUTIONS`
   (по кодам, флагам 1/0, названиям категорий, «остальное»). Сумма вкладов точно равна
   «SA Все товары и услуги». На графике месяцы сгруппированы по кварталам.
3. **Накопленная** — накопленная с начала года инфляция (хедлайн): текущий год, прошлый год
   и еще `CUMULATIVE_PALE_YEARS` лет бледной голубо-сиреневой шкалой (чем старше год, тем
   светлее); в таблице — все годы.
4. **Монетарная и немонетарная** — по флагу «Монетар. Инфляция» (детальные категории),
   два графика: м./м. и г./г.
5. **Матрица** — инфляция vs разброс изменений цен по корзине за 3 года: последние 3 месяца —
   розовым, остальной текущий год — темно-синим, прошлые годы — бледно; подписаны все точки.
6. **Топ-5** — по группам 1, 11, 111, 0: м./м., г./г., вклад в хедлайн.
7. **Категории** — по листу на каждое название из `SELECTED_CATEGORIES`: м./м. и г./г.;
   накопленная с начала года в сравнении со всеми прошлыми годами.

Оформление: цвета — из брендбука; остальное — как принято в центре: Arial, заголовок слева
черным жирным, черные оси, ось Y справа, легенда снизу, без сетки, зазор столбцов 20%.

## Требования к исходному файлу

- Лист «Данные»: строка 1 — названия категорий; далее строки разметки (Код Росстат,
  Последний год, Группа, Код, Вал.курс, Монетар. Инфляция, Акцизы, SA — новые строки-флаги
  подхватываются автоматически); строки «Вес ГГГГ»; ниже — индексы м./м. (пред. месяц = 100).
- Коды составные, через «_» (`ЖКУ_РУ`, `ПР_ПО`); код ЖКУ автоматически означает и У (услуги).
- Лист «SA крупные категории»: SA-индексы категорий с SA = 1, названия столбцов — как на листе
  «Данные». Служебным «Прочие (для SA)» группа не присваивается (чтобы они не попадали
  в расчеты продов/непродов/услуг); во вкладах в SA-хедлайн они относятся к своей группе
  по коду или по блоку листа SA.

## Методология, кратко

- Агрегирование м./м. — по схеме Росстата (цепной индекс Ласпейреса): вес категории в месяце
  = годовой вес × накопленный с декабря индекс по предыдущий месяц, как на листе
  «Расчет прочих».
- Базовая инфляция (`CORE_BASIS`): по умолчанию — крупные SA-категории; и отбор категорий
  (волатильность, усечение), и агрегирование — по SA-данным. Методы: без 20% наиболее
  волатильных (дисперсия м./м. за 3 месяца, по числу категорий; ряд начинается на 2 месяца
  позже начала данных), усечение 10%/10% (по весу), исключение (РУ, ЖКУ, ПО, С, А, ТМ, ТНМ),
  исключение без туризма (+ ВТ, ЗТ).
- Флаги 1/0 используются только явным сравнением («флаг = 1» / «флаг = 0»), не как множители.

## Проверки при запуске

В Jupyter печатаются: сверка агрегатов из детальных категорий с индексами Росстата;
сверка SA-хедлайна со столбцом «SA Все товары и услуги» (а если вклады групп разойдутся
с вашими столбцами «SA …» — предупреждение); незаполненная разметка крупных категорий;
коды исключений, которых нет в данных; что именно исключено в каждом методе базовой инфляции
на последнюю дату (включая список 20% наиболее волатильных).
